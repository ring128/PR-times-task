## 改善一覧

### 1. MySQLの起動完了を待機してappを起動
- 観測: Web側で起動する際にエラーを確認。
- 仮説: エラーコードではPHPがMySQLに接続しようとした際、MySQLがport:3306で接続を受け付けていなかったことから、PHPの接続を待機させることで必ず接続可能に。
- 変更: MySQLが接続受付を開始した直後でPHPを接続させるようにした。
- 検証: 動作確認済み。

### 2. 投稿一覧のN+1クエリ削減
- 観測: `make_posts` は投稿ループ内でコメント数・コメント・投稿者を取得し、さらにコメントごとに投稿者を取得していた。投稿数・コメント数に応じてSQL発行回数が増える構造だった。
- 仮説: 関連データを投稿ID・ユーザーID単位でまとめて取得し、PHP側で対応付ければ、SQL発行回数を投稿数・コメント数への依存から減らせる。
- 変更: コメント数、コメント、投稿者、コメント投稿者をそれぞれ一括取得し、取得結果をIDで対応付けるように変更した。
- 検証: ホーム・投稿一覧・ユーザーページ・投稿詳細で表示内容とコメント順を確認し、同一条件でベンチマークを実行する。
